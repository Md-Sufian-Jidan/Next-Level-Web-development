# 54-1: What are Docker Images & Containers

## Docker Image & Container Concept

```txt
Dockerfile → Docker Image (Read-only) → Docker Container (Read & Write)
```

* **Dockerfile:** এখানে অ্যাপ রান করার সকল instruction লেখা থাকে।
* **Docker Image:** Dockerfile থেকে তৈরি হয়। এটি একটি read-only blueprint/template।
* **Docker Container:** Image থেকে তৈরি running instance। এখানে data read/write করা যায়।

# 54-2: Understanding Image Types & Using Pre-built Images

## Docker Image Types

### 1. Base Images

* একদম basic operating system image
* Example: Ubuntu

### 2. Official Images

* Docker Hub এ Docker team বা official maintainers provide করে
* Example: Node, MongoDB, Nginx

### 3. Custom Images

* Developer নিজের প্রয়োজন অনুযায়ী তৈরি করে
* Example: নিজের app এর image

# Important Docker Commands

## Docker Image Build করার জন্য

```bash
docker build -t my-image .
```

* `-t` দিয়ে image এর name/tag দেওয়া হয়
* `.` মানে current directory এর Dockerfile use হবে

---

## সব Docker Images দেখার জন্য

```bash
docker images
```

---

## Docker Container তৈরি ও রান করার জন্য

```bash
docker run --name my-container my-image:latest
```

* `--name` দিয়ে container এর নাম দেওয়া হয়
* `my-image:latest` হলো image name ও tag

---

## Dangling Image

যে image এর কোনো নাম বা tag থাকে না তাকে **Dangling Image** বলে।
